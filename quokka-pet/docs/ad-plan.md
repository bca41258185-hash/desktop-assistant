# 庫卡助理 介紹廣告 製作計畫（第二版）

> 給在你自己電腦上開的 Claude Code 工作階段讀的。
> 目標：一支約 2 分鐘、1920×1080、**每秒 60 格**、精彩有趣活潑可愛的介紹廣告。
> 分支：`claude/amazing-fermat-6tay4w`。腳本完成後會放在 `quokka-pet/tools/ad/`（見第 6 節）。

---

## 1. 原則（不能違反）

1. **不誇大**：畫面上只出現程式真的會做的動作、真的會說的話。
   - 字卡屬於旁白，可以另外寫；角色氣泡裡的台詞必須是程式本身產生的。
   - 不能用腳本移動角色，做出程式沒有的效果。例如第一版的「從畫面底部探頭跳上來」，這版不能再用。
   - 提醒要真的設定時間，讓程式自己的排程觸發（可以用虛擬時鐘快轉）。
2. **不失真**：每段都用原尺寸算圖。不放大舊影片，也不用色鍵去背。庫卡要大，就讓程式本身畫大（舞台縮放或 zoom）。
3. **不卡**：用逐格算圖，每格前進 1/60 秒，等畫面畫好才存。畫面不受機器快慢影響。
4. **不侵權**：
   - 配樂與音效全部用程式自己合成。
   - 不出現任何真實軟體或品牌的商標。
   - 股票用虛構的代號和價格，角落標「虛構示意資料」。

## 2. 創意方向

- **前 3 秒抓住人**：第一個畫面就是庫卡臉部特寫，牠跳起來配一聲「啵」，打出大字「你的桌面，需要一隻庫卡。」接著快速閃過「事情太多記不住」的情境。
- **一天的故事**：不要像功能清單，而是跟著時間走，字卡標時間（09:00、15:00、18:00）。
- **反差和搞笑**：
  - 漲停轉圈和跌停抱頭用左右分割畫面。
  - 同一檔股票，兩隻不同個性講出不同的話，左右並排。
  - 被拎起來甩到頭暈、籃球沒進去追球，這兩處加慢動作和滑稽音效。
- **剪輯跟著節拍**：
  - 玩耍段每 1–2 拍切一刀。
  - 字卡在重拍上彈出。
  - 配樂起伏：開場強、中段最熱鬧、戀愛段溫柔、片尾大和弦。
- **多用特寫**：眨眼、看游標、頭暈的眼睛，每段至少一個近景。
- **畫面飽滿**：角色至少佔畫面高度的 1/3。
- **片尾記憶點**：全部一起跳的那一下用慢動作，接著彈出標題，最後一句行動呼籲。
- **字卡文案**：短、口語、有個性，每張 10 字以內為佳。

## 4. 技術流程

1. **啟動**：用 Playwright 的 `_electron` 啟動程式。
   - 每段用各自的設定資料夾，預先放好要出場的庫卡。
   - 主行程把 `screen.getCursorScreenPoint` 固定，或由腳本控制，避免真實游標干擾走位。
2. **虛擬時鐘**：在頁面載入前覆寫以下函式，讓時間只在腳本推進時才前進：
   - 舞台：`performance.now`、`Date.now`、`requestAnimationFrame`、`setTimeout`／`setInterval`。
   - 主行程：提醒排程用到的時間也要同步快轉，或把提醒設在幾秒後。
3. **逐格算圖**：每次前進 1/60 秒，等所有 `<img>` 解碼完成，再用 `webContents.capturePage()` 存成 PNG。
4. **驗證**：先算 3 秒測試片段，用 ffmpeg `mpdecimate` 量「每秒不同畫格數」，要接近 60 才開始大量算圖。
5. **背景**：自製假桌面（奶油色到淺綠的漸層，加上無品牌圖示）直接放在舞台後面一起算圖，不用色鍵。時鐘要和面板時間一致，或者不顯示時間。
6. **字卡**：用 HTML 產生 PNG，風格照 `ad/scene1–4.png`（暖綠、奶油色、粗圓字），進場要有彈跳。
7. **配樂**：用 Python numpy 合成。
   - 規格：120 BPM，木琴、鐘琴主旋律，加貝斯和輕鼓。
   - 音效：叮、啵、拍球、羽球擊球、排球擊球、咻、彈簧聲。
   - 段落要對齊剪輯；整體響度約 −16 LUFS，真峰值低於 −1 dBTP。
8. **合成**：ffmpeg 輸出 H.264 High（CRF 約 16）加 AAC 192k，60fps。
9. **檢查**：對成片每秒取 1 格拼成格圖，再對接觸點逐格看。要確認字幕沒被切到、沒有空白格、沒有穿模或閃格。

## 5. 時程

1. **預覽版**：先用目前的程式、較低解析度算一版，用來確認節奏和畫面。
2. **正式版**：等動作修正和 60fps 效能優化完成、測試通過後，用最終程式一個指令重跑全部，輸出 1920×1080。

預估時間：在沒有 GPU 的雲端環境，2 分鐘 × 60 格 ≈ 7,200 格，大約 25–60 分鐘；在有 GPU 的電腦上會快很多。

## 6. 在你自己的電腦上執行

腳本完成後會整理到 `quokka-pet/tools/ad/`，路徑一律用相對路徑。預計的用法如下：

```bash
cd quokka-pet && npm install
```

```bash
pip install numpy
```

```bash
bash tools/ad/render_all.sh --preview
```

```bash
bash tools/ad/render_all.sh
```

需要安裝：Node.js、Python 3（numpy）、ffmpeg。Windows 請在 Git Bash 或 WSL 執行。

輸出會放在 `quokka-pet/tools/ad/out/`（不會提交到 git）。

> 目前（本文件撰寫時）腳本還在雲端工作階段製作中，`tools/ad/` 會在預覽流程測通後提交。在那之前，你的工作階段可以先讀這份計畫，給意見或調整分鏡。

## 7. 已知風險

- **動作瑕疵**：動作修正尚未完成。預覽版可能還看得到跳格、帽子大小突變等問題，正式版要等修正和審查通過。
- **虛擬時鐘**：如果有些計時沒被覆寫到（例如主行程的計時器），快轉時兩邊的時間可能對不上。腳本會在每段開頭檢查。
- **字型**：雲端環境只有黑體，字卡用描邊模擬圓體。如果你的電腦有授權允許商用的圓體字，可以替換，效果會更可愛。
