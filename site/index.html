目前開放六位

你想請誰來盯？

都是兩千多年前的思想家，畫成 Q 版。每位有自己的個性：Claude 做事時他會照自己的脾氣說兩句，沒事時還會和其他人鬥嘴。框裡是他們會說的話。

三步開始

一分鐘就能上手

  1. 裝好、打開助手會出現在螢幕右下角，可以拖到你喜歡的位置。
  2. 按「📋 對話清單」再按「＋ 加入對話」，點你要盯的那個 Claude 對話。
  3. 開啟「即時提醒」清單上方的黃色提示按「開啟」，之後就能在泡泡上直接回答 Claude。

免費下載

把他們請到你的桌面

安裝版DesktopMaster-Setup-0.1.0.exe 免安裝版DesktopMaster-0.1.0-win.exe

第一次打開時

  • 這個程式沒有購買數位簽章，Windows 可能跳出「已保護您的電腦」。
  • 按「其他資訊」，再按「仍要執行」就可以了。

需要什麼

  • Windows 10 或 11。
  • Claude 桌面版的 Code 分頁，或 Claude Code。
  • 「即時提醒」需要電腦上有 Node.js；沒有也能用，只是提醒會慢一點、不能在泡泡上回答。

你的資料

  • 只讀取你電腦裡的 Claude 對話紀錄，不會修改它們。
  • 所有內容都留在你的電腦，不會上傳到任何地方。
  • 開啟「即時提醒」會在 Claude 的設定加一小段，隨時可以關掉還原。
